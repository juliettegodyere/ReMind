# 🧠 Contributing to ReMind

Thank you for your interest in contributing to **ReMind**!  
ReMind is a beginner-friendly open-source project that helps users learn and recall effectively using AI and memory-based learning techniques.

---

## 💻 How to Contribute

1. **Fork** this repository to your GitHub account.  
2. **Clone** your fork to your local machine:
   ```bash
   git clone https://github.com/juliettegodyere/ReMind.git
```

### Create and switch to the development branch:
```bash
git checkout -b dev
```

## 🚀 Submitting Changes

When you’ve made your changes:

1. Push your dev branch to your fork:
```bash
git push origin dev
```

2. Open a Pull Request (PR) to the main repository’s dev branch (not main yet).

Give your PR a short title (e.g., Add recall comparison logic).
Include a short description of what you changed.

3. After review and approval by the maintainers, your PR will be merged into the dev branch.

## 🧩 Merging to main

- Only maintainers can merge dev → main.
- Merges happen only after testing, review, and approval.
- Each merge into main must be stable, bug-free, and tested.

## ✨ Coding Guidelines

- Write clear, simple, and well-documented code.
- Use PEP 8 style conventions (Python standard).
